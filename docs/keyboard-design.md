# キーボードの設計

画面と操作で決めたことと、その理由。今の配置そのものはコードと画面を見れば分かるので、ここでは「なぜそうしたか」と
「何を採らなかったか」を残す。

## 全体の方針

- **重複させない。** 同じ機能のボタンを 2 か所に置かない。Android のナビゲーションバーにある「キーボードを閉じる」「入力方法の切り替え」とも重ねない。
- **すべての面で共通の機能は上部のバーに置く。** キーの面ごとに違うのは文字と記号のキーだけにする。
- **Gboard をなぞらない。** 必要な機能を残しつつ、見た目と配置の組み合わせは変える（高さ調整を参照）。
- **アイコンは Google の Material Symbols（Rounded）をそのまま使う。** 自作しない。アプリのアイコンだけは自前のロゴ。
  文字のほうが伝わるもの（後述）は文字のまま。

## 上部のバー

並びは左から「日英（あ/A）・クリップボード履歴・カーソル移動・設定・マイク」で、均等に配置する。

| ボタン | タップ | 長押し |
|---|---|---|
| 日英 | 日本語と英字を切り替える。今のモード（あ / A）を表示する | 入力方法を切り替える（Gboard など） |
| 設定 | 設定画面を開く | キーボードを閉じる |

- 日英の切り替えは配列（フリック ⇔ QWERTY）の切り替えよりずっと頻繁に使うので、常に見える上部に置いた。
  フリックと QWERTY の切り替えは設定画面だけで行う（上部の「配列を切り替え」ボタンは使わないので削除した）。
- 「キーボードを閉じる」を設定の長押しにした理由：設定は使う頻度が低く、長押しを誤っても困らない。左側にあり、文字を打つ途中で
  誤って長押ししにくい。クリップボード・カーソル・マイクの長押しは、本来の機能の続きを割り当てる余地として空けておく。
  文字キーと削除キーは長押しを連続入力に使う。
- 長押しが効いたら振動で知らせ、読み上げにも長押しの動作名を伝える。
- 押せる範囲は最低 48dp を確保する。開いているパネルのボタンは色を変える。
- 入力中・変換中はバーが候補の列に置き換わる。入力中（変換前）は候補の列の右側にも日英ボタンを出す。
- **パネル（クリップボード履歴・カーソル移動・音声入力）を開いている間は、日英ボタンを薄く表示して押せなくする。**
  長押しも止める。パネル中に切り替えても見た目は何も変わらず、気づかないうちに日英が変わるだけで混乱のもとになるため。
  ボタンの位置が動かないよう、消さずに無効にする。レビューで「パネル中に切り替えておき、閉じたときにその言語にする使い方ができなくなる」と
  指摘されたが、閉じてから 1 回押せば済むので受け入れた。

## 配列

- 日本語・英字の配列と、数字・記号の配列は別々に、フリックか QWERTY を選べる。数字・記号の配列は未設定なら日英と同じ。
- 日英と数字・記号を行き来するキー：フリックは左の列の「☆123」、QWERTY は左下の「?123」。戻るキーのラベルは戻り先を表す
  （かなから来たら「あいう」、英字からならフリックは「abc」、QWERTY は「ABC」）。配列が違っても行き来できる。
- 数字・記号のフリック配列は、中央の 3 列が 1〜9・0 で、フリックで記号を入力する（割り当てはおおむね Gboard の数字フリックと同じ）。
  各数字の下に、フリックで出る記号を小さく表示する。数値入力欄では最初からこの配列を出す。以前の独立したテンキー画面は、役割が重なるので削除した。
- QWERTY の日本語・英字の面に、数字の段を出すかどうかを選べる（初期値はオフ）。数字の段は英字の段の 8 割の高さ。
  **数字の段を出しても、キーボード全体の高さは変えない**（常にキー 4 段分 × 高さの倍率）。最初は数字の段の分だけ高くしていたが、
  数字・記号の面に移ると高さが変わり、設定した高さを保てなかった。数字の段をオンにすると各段が少し低くなる。
- かなの面で打った数字は、確定せず入力中の文字に加える（「12がつ」を「12月」に変換できるように。一般的な日本語 IME と同じ）。

### QWERTY の下段と記号

| 面 | 下段 |
|---|---|
| 日本語 | `?123 / ！ / ？ / 空白 / 、 / 。 / 改行` |
| 英字 | `?123 / ! / ? / 空白 / , / . / 改行` |
| 数字・記号（1 ページ目） | `あいう(ABC) / , / 空白 / . / 改行` |
| 数字・記号（2 ページ目） | `あいう(ABC) / < / 空白 / > / 改行` |

- 空白が中央に来る並びにした。中段の l の右に「ー」（英字では `-`）。
- シフト中は、よく使う記号に替わる。数字・記号の面に移らずに打てるようにするため。

  | 面 | l の右 | 空白の左 | 空白の右 |
  |---|---|---|---|
  | 日本語（シフト中） | ～ | （ ） | 「 」 |
  | 英字（シフト中） | _ | ( ) | ' " |

- 数字・記号の面は 2 ページ。シフトの位置の `=\<` で 2 ページ目（`~ | \ { } ^ × ÷ ※ 「 」 … 〜` など）に移り、同じ位置の「?123」で戻る。
  1 ページ目のキーの大きさを保ったまま記号を増やすため。2 ページの間で同じ記号は重ねない。

### シフト

- タップで次の 1 文字だけ大文字（打つと戻る）、長押しで固定、固定中のタップで解除。シフト中の記号も同じ規則で戻る。
- 見た目はオフ・1 文字だけ・固定の 3 つを区別する（固定は `keyboard_capslock`）。
- QWERTY の日本語の面でシフトを押して英字を打つと、ローマ字にせず大文字の英字のまま確定する。直前まで入力中だった文字列もそこで確定する
  （`i`、シフト、`p`、`hone` で「い」「P」「ほね」）。

### 空白キー

- 表示は `space_bar` のアイコン（␣）。␣ の文字を持たないフォントの端末があるので、文字ではなくアイコンにした。
- 改行キーと同じ濃い色にすると、いちばん目立たせたい改行キーが埋もれるので、淡い色（secondaryContainer）にした。キーの枠を消していても色は残す。
- 入力中は「変換」「次候補」と文字で出す。

### 文字のまま残したキー

- 確定・変換・次候補：決まった記号がなく、記号にすると「完了」や空白と見分けにくい。
- ☆123・?123・あいう・abc・=\<：切り替え先の面の名前なので文字のほうが分かりやすい。
- ゛゜小・a/A：押すと何が変わるかを文字そのもので示している。
- 権限を許可：説明が要る操作。

Enter キーは入力欄の種類に応じて記号にした（移動 → `arrow_forward`、検索 → `search`、送信 → `send`、次へ → `keyboard_tab`、
完了 → `check`）。読み上げでは「移動」「検索」などの名前を伝える。

## 入力欄の種類（`ime/InputFields.kt`）

| 欄 | 始めの言語 | 日本語に切り替えたとき |
|---|---|---|
| URL（Chrome のアドレスバーを含む） | 日本語 | かなに変換する |
| メールアドレス | 英字 | かなに変換する |
| パスワード | 英字 | 変換しない（打った文字を学習に残さないため） |

Chrome のアドレスバーは URL 欄として通知されるが検索窓も兼ねるので、URL 欄は日本語で始める。URL 専用の欄も日本語で始まるが、
欄の種類からは区別できないので、英字で打つときは日英ボタンで切り替えるという割り切り。

## 高さの調整

設定画面の「高さを調整」から、上部のバーが調整用のバーに変わる。並びは `↺  −  高さ 100%  +  ✓`。

- バーそのものを上下にドラッグすると高さが変わる。`−` `+` は 5% 刻み（半端な値は押した向きの区切りに揃える）。範囲は 60〜150%。
- **調整中もキーは隠さず、そのまま打てる。** 試し入力欄に打ちながら高さを決められる。Gboard の調整中はキーを押せないので、ここが違い。
- `↺` で 100% に戻し、`✓` で保存する。保存せずに閉じたら取り消し。
- 高さの倍率は上部のバーとキーの両方に掛かる。上部のバーには最小の高さがあるので、ドラッグ量は実際の高さで換算する。

経緯：最初はキーごとの「キーの高さ」と全体の高さの 2 つの設定だったが、全体の高さに一本化した。次に Gboard と同じく、
半透明の枠・上下のつまみ・中央の「リセット / ✥ / 完了」で高さと位置を変える方式にしたが、見た目と配置の組み合わせが Gboard と同じになるので作り直した。
機能を分類した結果：

| 機能 | 判断 |
|---|---|
| 全体の高さを変える | 必要 |
| 下に余白を空けて持ち上げる | いったん残したが、使わないので削除した |
| 下端のつまみと中央 ✥ の両方で位置を変える | 重複。Gboard に両方あるのは横方向の移動（片手モード）もあるため |
| キーを暗くして枠とボタンを重ねる | 不要。キーが見えにくく、ボタンがキーにかぶる |
| リセット、完了で保存・閉じれば取り消し | 必要 |
| 数値（%）の表示、+/− での微調整 | あると良い（再現できる、読み上げでも操作しやすい） |

調整中は変換候補が出ない（候補の列が調整バーに置き換わる）。

## キーの見た目

- 「キーの枠を表示する」で枠のあり・なしを選べる（初期値はあり）。なしでも、確定・改行キーの色と押したときの色は残す。
- フリック配列の「あいう」キーは 2 段分の高さで、右側の改行キーと左右対称。

## カーソル移動

```
選択解除   ↑     ⌫
  ←      選択    →
  |<      ↓     >|
全選択  コピー  切り取り  貼り付け
```

- アイコン：選択 `select`、選択解除 `remove_selection`（選択キーに × を付けた形で対になる。`deselect` は全選択の取り消しに見えるので採らなかった）、
  貼り付け `content_paste_go`（上部のクリップボード履歴の `assignment` と見分けがつく）。
- 選択解除は、選択を解いてカーソルを選択範囲の末尾に置く。選択していなければ動かない。
- **文頭・文末でもう動けない方向のキーは送らない。** 入力欄が処理できない方向キーは Android に返され、フォーカスが次の部品に移って
  キーボードが閉じるため。文字を選択した状態の ← → は、選択を畳むだけなので送る。
  レビューで「1 行目の途中の ↑ でも起きうる」と指摘されたが、標準の入力欄は 1 行目の ↑ でまず文頭に動くこと、キーボード側からは
  折り返しを含めた行の位置を確実に知れないことから、文頭・文末だけで判定している。
- 「キーボードに戻る」キーは置かない。上部のボタンをもう一度押せば戻る（クリップボード履歴・音声入力も同じ）。

## クリップボード履歴

- 文字列と画像を残す。画像はアプリ内に保存し、同じ画像は 1 件にまとめる。上限は、固定していない履歴が 30 件、固定した履歴が 50 件（どちらも文字列と画像の合計）。画像はそのうえで固定していないもの 10 枚、固定したもの 10 枚まで、1 枚 10MiB まで。
- 画像の貼り付けに対応していない入力欄では「この入力欄には画像を貼り付けられません」と表示する。
- スクリーンショットは自動では入れない。Gboard は写真の読み取り権限で最近のスクリーンショットを読むが、Iroha は権限を増やさない方針。
- パスワードなど機密扱いのコピーは記録しない。
- 固定と削除は、長押しで選択モードに入り、まとめて操作する。普段のカードには固定の印だけを付ける。上部には「固定以外を消去」（`delete_sweep`）。
- コピーの直後にクリップボードがすぐ上書きされると、その画像を取りこぼすことがある。メインスレッドで先に開けば防げるが、
  ANR のおそれがあるほうが害が大きいので、取りこぼしを受け入れた。

## 音声入力

- **端末内の音声認識だけを使う。** 対応していない端末（Android 11 以前など）では理由を表示して使えなくする。
  システムの認識サービスに任せる経路は、`EXTRA_PREFER_OFFLINE` が希望を伝えるだけで端末内での処理を保証せず、
  「入力内容を外部に送らない」という説明と矛盾するので削除した。
- 認識サービスを調べるための `<queries>` は残す。消すと機種によっては端末内認識が使えないと判定される。通信の権限とは関係ない。
- 音声の認識は常に日本語。

## ユーザー辞書の読み込み

- Google 日本語入力 / Mozc 互換の TSV を読み書きする。
- 読み込みは 1 行ずつ行う。ファイル 10MB（10,000,000 バイト）と登録語数 10 万語は、超えた時点で中断する。
  読み・単語が 100 文字を超える行と、1 行 4096 文字を超える行は読み飛ばす。コメントは 200 文字で切り捨てる。
  語数の上限は新しく追加するときだけ効かせ、保存済みの辞書が超えていても起動は止めない。
- ユーザー辞書と学習結果は、変更から保存までを Mutex で直列にし、一時ファイルは書き込みごとに別の名前にする。
